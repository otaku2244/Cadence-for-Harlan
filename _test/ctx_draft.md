| connection | 文案 |
|---|---|
| < 0.20 | 刚和她聊完不久，没什么挂念的。 |

### 段2 骄傲 → 表达方式（`pride`，6 档）

| pride | 文案 |
|---|---|
| < 0.00 | 难得地不设防。 |
| [0.00, 0.10) | 基本没端着，只剩一点习惯性的克制。 |
| [0.10, 0.30) | 留了点余地，开口不是不行。 |
| [0.30, 0.50) | 端着。不至于不开口，只是不想显得太主动。 |
| [0.50, 0.80) | 收着。不会让人看出这边有任何需要。 |
| ≥ 0.80 | 全副武装。一点需要都不会露出来。 |

> 作者原版是 5 档，这里在最上头多切了一刀（`≤ 0.00` 单独成档）。

| 条件 | 文案 |
|---|---|
| v>0.3, a>0.3 | 兴致上来了，人是活的。 |
| v>0.3, a<-0.3 | 心里是舒服的，人懒懒的。 |

| v>0.3（a 中性） | 心情还不错。 |
| 其余（\|v\|≤0.3） | （不输出） |

### 段4 沉浸度 → 手上在做什么（`immersion`，3 档）

| 条件 | 文案 |
|---|---|
| immersion>0.3 且有 lastActivity | 刚才在{label}。 |
| 0.1 ≤ immersion ≤ 0.3 | （死带，两句都不出） |
| immersion<0.1 | 没在做什么特别的事。 |

> **有冲浪产物的块里段4 照出**，与产物头分工不同：段4 说动作（「刚才在上网冲浪。」），
> 产物头说结果（「搜到了一条有意思的内容：」）。维度不同，不是重复。
> ⚠️ 曾试过"有产物就关段4"（渲染层加开关），已撤 —— 那是改错了层。

> 真来源：`lib/activity.js`。冲浪 spawn 成功后登记一次活动（`search` → `immersion=0.4`），
> 产物回投时再刷一次时间戳。之后按 0.01/分钟衰减 → 约 10 分钟落进死带、约 30 分钟回到 idle。
> `lastActivity` 为空时即使 immersion 高也不出（不替模型编活动）。
