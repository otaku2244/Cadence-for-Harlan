## 一、你的方案成立

`END_MARKERS` **登两条**就是"两种情况都跳过"，不是二选一：

```
EXTERNAL_CONTEXT_BLOCK_END_MARKERS = {
    "此状态为潜意识的底色沉淀，自然浸润在回应里，不作任何元说明或刻意提及。",   ← 无产物（现状）
    "以上为你独处时的真实切片，你可以留下你的独自思考、也可以把内容直接呈现给她，如何行动由你决定。",  ← 有产物（新增）
}
```

有产物用第二条、没产物用第一条，各成各的对。原有三个场景（此刻 / 找她 / 独处）实测**全都没被带坏**。

我上一版把两句合并成一句，是多余的。合并的唯一动机是我误以为"边界句必须活到块尾"——实际上它降级成**裸行**放进块内就行，照样被跳过态吃掉。不用改你的文案。

## 三、为什么必须去掉内层【】

`chat_context.py::_strip_external_context_blocks` 见到**任何**行首【X】都重算一次 `skipping = (X in EXTERNAL_CONTEXT_BLOCK_TITLES)`。内层那个标题不在白名单里 → 跳过态提前关闭 → 标题、网址、原图、摘要**全部原样泄漏**，会被当成她的话进归档与检索 query。

三条对照实测：

| 形状 | 结果 |
|---|---|
| 内层带【】（你的草稿原样） | ❌ 产物全泄漏进归档 |
| 内层裸行 | ✅ 只剩她的原话 |
| 内层带【】+ 登记进 TITLES 白名单 | ✅ 但要在 Lattice 塞一条极具体字符串，不如去括号干净 |

**采纳去括号。**

## 五、两个残留风险

**① 压行。** 记忆里记着 `cadence_pull` 会压 notice 成单行，但当前 `cadence-operit/cadence_pull.js` **没有压**，工作流提取正则是 `PROMPT_START\r?\n([\s\S]*?)\r?\nPROMPT_END`（`[\s\S]*?` 跨行安全）。两者矛盾 → 手机上那份可能是旧的。压行实测会让整块被吞、连她的话一起没。**落地前设备侧确认。**

**② 残块。** 块头在、尾句丢（网关截断/传输中断）→ 跳过态持续到消息结尾 → 她的原话整段被吞，返回 `''`。这是契约的固有代价，`END_MARKERS` 解决不了。唯一缓解是投递前 `assertBlockShape` 拦（已在 `fireProactive` 里），跨设备那一段靠不住。
